# 08. 후속 에이전트 인계: 준비된 키와 추가 API 요청

업데이트: 2026-11-10 (Asia/Seoul). 사용자 지시를 구현 작업에 인계하는 문서다.

## 먼저 확인할 준비 사항

작업 루트는 `<workspace>`다. 다음 네 파일은 존재를 확인했다. 이번 설계 작업에서는 본문·길이·해시를 읽거나 인증을 시험하지 않았다.

| 연결 | 준비된 파일 | 런타임 환경변수 | 후속 점검 |
|---|---|---|---|
| 공공데이터포털 | `<workspace>\data_gov_key.txt` | DATA_GO_KR_SERVICE_KEY | 서비스별 승인·키 표현형·한도 |
| Hugging Face | `<workspace>\hf_token.txt` | HF_TOKEN | namespace·대상 private repo·읽기/쓰기 권한 |
| 한국부동산원 R-ONE | `<workspace>\rone_key.txt` | RONE_API_KEY | 사용할 통계표·시계열·제공 범위·한도 |
| 브이월드 | `<workspace>\vworld_key.txt` | VWORLD_API_KEY | 서버 호출·등록 URL/도메인 조건·데이터별 접근 |

이미 준비된 키를 다시 발급하거나 채팅으로 보내 달라고 요청하지 않는다. 구현이 승인된 작업에서는 credential loader가 명시한 파일만 읽어 필요한 실행 단계에 주입한다. 키는 모델 입력·도구 결과·로그·예외·Git·HF 업로드·문서에 노출하지 않는다. 환경변수 우선순위와 오류 처리 계약은 [04_CONNECTORS_AND_SECRETS.md](04_CONNECTORS_AND_SECRETS.md)를 따른다.

같은 폴더의 다른 키 파일은 자동 사용하지 않는다. 추가 자격증명이 필요하면 기존 연결과 승인 범위를 확인하고 실제 필요한 항목을 사용자에게 요청한다. 키 파일 존재와 인증 성공, 특정 데이터의 이용 권한은 별개다.

## 사용자에게 추가 API를 요청하는 규칙

1. 현재 구현할 기능과 필요한 데이터·기간·지역·필드를 먼저 확정한다.
2. services registry, 위 네 연결, 사용자가 알려준 기존 승인으로 처리 가능한지 확인한다. 최신 공식 문서에서 실제 제공처·명세·신청 링크를 확인한다.
3. 단순 인자·파서·네트워크 오류를 미승인으로 단정하지 않는다. 인증/권한/쿼터/장애를 비밀 없는 오류 정보로 구분한다.
4. 추가 API·승인·키·도메인 등록·한도 증액이 실제로 필요하면 그 시점에 사용자에게 요청한다. 같은 연결을 반복 요청하지 않도록 요청 대장을 확인한다.
5. 요청에는 API/기관, 필요한 이유, 신청 링크, 필요한 기능·권한·한도, 권장 파일명 또는 Secret 이름, 막힌 작업과 계속할 작업을 적는다.
6. 키 값 자체를 채팅에 붙여 달라고 하지 않는다. 사용자가 로컬 키 파일 또는 Secret에 저장하면 에이전트는 값 없이 파일명·준비 여부만 확인한다.
7. 필요한 승인이 도착할 때까지 의존 기능만 pending-user로 표시한다. 독립적인 수집기·스키마·fixture·문서·조회 구현은 계속한다. 승인 전 호출·유료 가입·서비스 조건 동의·임의 권한 확대를 하지 않는다.
8. 연결 확인 후 registry와 아래 대장을 갱신한다. 조회하지 못한 필드를 임의 추정하거나 다른 데이터로 조용히 대체하지 않는다.

## 필요할 때 검토할 후보

다음은 새 신청 요구가 확정된 목록이 아니다. 실제 기능의 필요와 기존 키의 제공 범위를 먼저 대조한다.

| 후보 | 필요해지는 조건 | 요청 판단 |
|---|---|---|
| 주소 검색·좌표 API | 표준 주소·건물 식별·좌표 연결이 기존 제공처로 충분하지 않을 때 | 주소기반산업지원서비스 등 공식 명세 확인 후 요청 |
| 법령 공동활용의 추가 범위 | 현행/연혁·자치법규·고시·판례·해석 원문이 기존 연결로 부족할 때 | 기존 KAPA·승인 범위 먼저 확인, 필요한 종류만 요청 |
| 개별/표준지 공시지가·공시가격 | 평가에 필요한 연도·필드·표준지 정보를 현재 브이월드 등에서 얻지 못할 때 | 두 가격 유형 구별, 실제 제공기관과 신청 경로 확인 |
| 지역 고시·지구단위계획·도시계획 자료 | 필지 규제 판단에 API 요약 외 고시·도면·조서가 필요할 때 | 공개 파일로 해결 가능한지 먼저 확인, 필요 시 지자체 요청 |
| 추가 공공데이터포털 서비스 승인 | 토지·건축물·상업용 등 신규 유형 구현 시 해당 서비스가 미승인일 때 | 기존 키를 유지하고 해당 서비스 활용신청만 요청 가능 |
| R-ONE 통계 추가 범위·호출 한도 | 필요한 지가/가격/임대 시계열 또는 호출량이 현재 범위 밖일 때 | 준비된 rone_key로 가능한 범위 먼저 확인 |
| 브이월드 등록 조건·호출 한도 | 서버 환경·도메인·데이터 종류·쿼터로 접근이 막힐 때 | 새 키 요청 전에 기존 키 설정 변경 필요 여부 확인 |
| 추가 통계·전문 물건 자료 | KOSIS·경제지표·어업/영업 등 특정 업무에서 실제 필요한 때 | 현재 의뢰와 직접 관련된 API만 요청 |

신청 URL·현재 요금·권한은 후속 요청 시 공식 문서로 다시 검증한다. 모든 후보를 선제적으로 신청하도록 요구하지 않는다.
